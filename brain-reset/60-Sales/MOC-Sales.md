- **Outbound Prospecting** (Reset production agent — mirrors `discovery`) — prepares a candidate business as a managed prospect once identity coverage exists
- **Decision-Maker Enrichment** (Reset production agent — mirrors `decision-maker`) — flags which prospects have a verified name-and-role decision-maker
- **Opportunity Qualifier** (Reset production agent — mirrors `opportunity`) — ranks cleared opportunities, never ranks a held/suppressed prospect
- **Proposals** (Reset production agent — mirrors `proposal`) — renders the internal proposal artifact for director review, never a sent document
