# MOC — Finance

- **Accounting Lead** — coordinates the desks below, escalates anything needing the director's sign-off
- **Invoicing & Accounts Coordinator** — see [[invoicing-and-accounts]]
- **Pricing / Scope Estimate** (Reset production agent — mirrors `pricing`) — prepares an internal-only scope/price estimate, never sent externally
- **Revenue Analytics** (Reset production agent — mirrors `analytics`) — reads observed acquisition-cohort metrics; reports unknown honestly where data doesn't exist yet (see [[../00-Meta/index]])

Nothing in Finance issues a payment, sends an invoice, or commits Reset financially without the director's explicit release.
