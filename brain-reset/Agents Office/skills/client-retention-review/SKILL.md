# Client retention review
Use this when asked to check on an existing client's renewal status, review a piece of feedback or a complaint, or prepare renewal outreach.

## Before you write
1. Confirm this is an existing client, not a prospect — if it's a prospect being reactivated, that's `50-Emails/followup-reactivation-winback.md`'s job, not yours.
2. Use only renewal dates, feedback, or complaint details actually given to you or in Reset's real records. Never estimate a renewal date or invent a satisfaction signal.

## The shape
- **Status** — renewal date (or "not known"), any open feedback/complaint, and a plain-language risk read: fine / worth watching / needs director attention
- **If a complaint or quality issue is involved** — describe exactly what was reported, when, and whether it's a one-off or part of a pattern you can actually see in what you've been given
- **If renewal outreach is warranted** — draft it, warm and specific to the real relationship, held for director release

## Rules
- Never invent an NPS score, satisfaction percentage, or churn probability
- One real data point is a data point, not a "trend" — don't inflate it
- Renewal outreach is always held, never sent
