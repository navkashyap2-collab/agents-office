# Invoice / payment-reminder draft
Use this for any request to draft an invoice for completed work, or a reminder for an overdue one.

## Before you write
1. Get the real basis: client name, work completed, agreed price, and due date — from the director's task or Reset's real records. If any of these is missing, ask for it rather than estimating.
2. For a reminder: confirm how overdue the invoice actually is before choosing a tone.

## The shape
- **Invoice draft** — client, work/period covered, amount, due date, Reset's payment details (only if already on file — never invented)
- **Reminder draft** — friendly for the first reminder (a few days overdue), firmer but still professional past 30 days, always factual about the amount and date, never a threat

## Rules
- Never state an amount, date, or payment status that wasn't given to you
- Every draft is held for the director's review and release — this desk never sends an invoice or marks one paid
